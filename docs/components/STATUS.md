**All adapters share the same trust boundary:** verified exact-version host guide, user-edited local review, deliberate Copy/Share, truthful output-use instructions, no provider lock-in, and no monitoring of agent answers. A host-owned file importer is separate; generated recipes remain untrusted and must not be executed unattended.

Priorities: run the [non-public versioned Maven preview](DISTRIBUTION.md), prepare reproducible distribution, and obtain independently authored consuming-host evidence after first-party S2+ packaging; verify real Unity/Godot/FlutterFlow editor exports; conduct device TalkBack, keyboard, large-text and recipient-ingestion trials; enforce host-specific version/locale guide truth under the [API/variant policy](../API_COMPATIBILITY.md) and [release-evidence standard](RELEASE-EVIDENCE.md). A normal feature-branch file update succeeded without bypass on November 1, resolving the earlier over-broad branch restriction. Its required-status-check list remains **empty**: admin [issue #73](https://github.com/gamesbyian/AYA/issues/73) still tracks requiring the GitHub Actions docs context and a verified failing-check merge-block negative control.

## November 2 source-guard and acceptance-ledger reconciliation

- **Structured-file kit parity:** [PR #105](https://github.com/gamesbyian/AYA/pull/105) merged after 12/12 exact-head workflows passed. Both Python authoring and Android runtime reject heading-only sections; Android additionally refuses unexpected nonblank material before the first structured-kit section. This remains a **structural** guard, not host-schema semantic verification or import acceptance.
- **Translation/filesystem kit integrity:** [PR #106](https://github.com/gamesbyian/AYA/pull/106) merged after 12/12 exact-head workflows passed. Both runtime and offline validators now reject empty/heading-only sections. Existing optional title and introductory text before the v1 headings remain supported. Its earlier [red Android run 41387285621](https://github.com/gamesbyian/AYA/actions/runs/41387285621) was caused by duplicated Kotlin test source, corrected on the final PR head, and remains recorded in the PR discussion.
- **Filesystem snapshot truth:** [PR #107](https://github.com/gamesbyian/AYA/pull/107) merged after 12/12 exact-head workflows passed. Android now rejects an absent/mistyped scan error list, contradictory complete-with-errors reports and truncated listings without a reason, while preserving explicitly disclosed scan-complete/listing-truncated cases. A first Godot Android smoke attempt failed on an ADB logcat transport error (exit 255); the **failed job only** was retried successfully within [run 41387778356](https://github.com/gamesbyian/AYA/actions/runs/41387778356). This is emulator boot/card evidence, **not** accepted Godot portrait screenshots or interaction/recipient evidence.
- **QA coverage:** [PR #108](https://github.com/gamesbyian/AYA/pull/108) merged after the exact-head always-on reference check passed. `aya-packet-trials/v1` now accepts all five documented packet profiles, including `filesystem`, without loosening exact-packet-hash, actual-ingestion or independently reviewed host-outcome gates. Synthetic test data do not certify a recipient.
- **Documentation truth:** [PR #109](https://github.com/gamesbyian/AYA/pull/109) merged after its reference check passed, listing Structured Artifact in the README and distinguishing the currently available source-preview launcher from the **unimplemented** optional current-artifact attachment.

**No release-tier promotion:** no public native SDK distribution, independently authored consuming-host release, actual third-party assistant ingestion, host importer round-trip, physical-device accessibility or independently accepted Godot portrait visuals has been established by these changes. Existing release and trust boundaries above remain open. The main branch ruleset still needs an administrator to require the always-on `docs` check; see [issue #73](https://github.com/gamesbyian/AYA/issues/73). Draft diagnostic [PR #100](https://github.com/gamesbyian/AYA/pull/100) remains deliberately unmerged.
