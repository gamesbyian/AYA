**All adapters share the same trust boundary:** verified exact-version host guide, user-edited local review, deliberate Copy/Share, truthful output-use instructions, no provider lock-in, and no monitoring of agent answers. A host-owned file importer is separate; generated recipes remain untrusted and must not be executed unattended.

Priorities: run the [non-public versioned Maven preview](DISTRIBUTION.md) and prepare reproducible distribution; complete Flutter built-in Kotlin migration and real Unity/Godot/FlutterFlow editor exports; conduct device TalkBack, keyboard, large-text and recipient-ingestion trials; enforce host-specific version/locale guide truth under the [API/variant policy](../API_COMPATIBILITY.md).
